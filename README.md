# أطلس السوق

تطبيق جوال عربي (RTL) مبني بـ Flutter لدراسة مواقع فروع الهايبر ماركت والتجزئة في المملكة العربية السعودية. يعمل دون إنترنت في وظائفه الأساسية، ويضيف البحث الحي والذكاء الاصطناعي عند توفر الاتصال.

## ما يفعله التطبيق الآن

- خريطة تعرض حدود المملكة (Natural Earth — ملكية عامة)، مراكز المناطق والمحافظات، و**1,164 فرعاً** من 11 علامة تجارية، مع تجميع للعلامات وفلترة حسب العلامة وطبقات قابلة للتبديل.
- تحديد موقع مرشح بالضغط المطول على الخريطة، أو بإحداثيات دقيقة، أو عبر GPS بعد إذن صريح، أو باختيار مرشح محفوظ.
- نطاق دراسة دائري قابل للتعديل (1–20 كم)، وكل نتيجة مبنية على **مسافة بخط مستقيم** وليست زمن قيادة.
- مؤشرات دراسة مع مصدر كل رقم وسنته وحالته: الفروع داخل النطاق، أقرب المنافسين، توزيع العلامات، السكان بالمستوى الجغرافي الصحيح، وجودة البيانات.
- فصل صريح بين: لم يُجرَ البحث / صفر نتيجة / فشل البحث / نتائج جزئية. لا تُفسَّر قلة نتائج مصدر مجتمعي على أنها غياب فعلي.
- مقارنة المرشحين جنباً إلى جنب مع تداخل النطاقات، مع رفض إصدار ترتيب موثوق عند نقص البيانات المشتركة.
- استيراد قوائم Excel عربية مع شاشة مراجعة (مقروء/مقبول/مرفوض، إحداثيات خاطئة، تكرارات) وتحديث ذري لمصدر واحد دون مسح المصادر الأخرى.
- تصدير تقرير Excel بأوراق عربية وخريطة HTML تفاعلية، مع حظر تحويل «لم يُبحث» إلى صفر أو عرض سكان المنطقة كـ «سكان الدائرة».
- تكامل Gemini اختياري بمفتاح المستخدم المحفوظ في keystore الجهاز فقط، مع التحقق من وجود الأرقام داخل صفحات المصادر قبل عرضها كاقتراح للمراجعة.
- قاعدة SQLite محلية مع نسخة احتياطية قابلة للحفظ.

## ما لم يُنجز بعد (مراحل لاحقة)

- زمن القيادة/المشي من خدمة طرق مرخّصة (لا يُستنتج من المسافة المستقيمة).
- بحث حي مرخّص عن المدارس والمستشفيات والتجزئة (يظهر الآن كـ «لم يُجرَ البحث» بدل صفر مزيف).
- تقدير سكان نطاق الموقع من مصدر سكاني مكاني مناسب (لا يُعرض حالياً إطلاقاً).
- توقعات المبيعات وأثر الافتتاح على الفروع الأخرى (تتطلب بيانات مبيعات فعلية ونموذجاً مُختبَر الدقة).
- خدمة خلفية تحفظ مفتاح المؤسسة بدلاً من مفتاح المستخدم، ودعم App Check.
- بلاطات مرخصة للعمل دون اتصال (لا تُحمّل بلاطات OSM العامة جماعياً).

## البنية

```
lib/
  core/        نماذج، ثيم، حسابات جغرافية، تنسيق عربي
  data/        مصادر الأصول، SQLite، محرك التحليل، Gemini، Excel، تصدير HTML
  state/       حالة التطبيق (ChangeNotifier + provider)
  features/    map · study · compare · data_sources · reports · settings
  widgets/     مكوّنات مشتركة (بطاقة مؤشر، حالة البحث، رسائل)
tools/
  prepare_data.py     إعادة توليد الأصول من الملفين الأصليين
  output/             نسخة التعداد المبسطة + قاموس البيانات
assets/data/          JSON مبسط للسكان والفروع والتقسيمات والحدود
```

### تبسيط ملف التعداد

الملف الأصلي يحتوي 13 ورقة و55 ألف سجل عمري مفصّل لا يستخدمه التطبيق. سكربت `tools/prepare_data.py` يستخرج الأعمدة الأهم فقط:

`geo_id، name_ar، name_en، unit_type، data_year، data_class، source_id، population_total، population_male، population_female، population_saudi، population_non_saudi، median_age، density`

وينتج `tools/output/Saudi_Population_Simplified.xlsx` مع `DATA_DICTIONARY.md`. الملف الأصلي لا يُعدَّل.

 لإعادة التوليد:
```powershell
python tools/prepare_data.py
```

```powershell
flutter analyze
flutter test

```

## البناء والتوقيع

GitHub Actions في `.github/workflows/build.yml` ينفّذ التحليل والاختبارات ثم يبني APK واحداً لمعمارية `arm64-v8a` فقط:

```
flutter build apk --release --target-platform android-arm64 --split-per-abi
```

لإنتاج نسخة رسمية قابلة للتحديث فوق بعضها، أضف Secrets في إعدادات المستودع:

| Secret | المعنى |
|---|---|
| `KEYSTORE_B64` | مفتاح التوقيع بصيغة base64 (لا يُضاف إلى المستودع) |
| `STORE_PASS` | كلمة متجر المفاتيح |
| `KEY_PASS` | كلمة المفتاح |
| `KEY_ALIAS` | اسم المفتاح |

بدون هذه الأسرار يُنتج APK بمفتاح تجريبي ويُسمّى «معاينة»، ولا يُقدَّم كإصدار رسمي. معرّف التطبيق ثابت: `com.aalhitari.atlas_souq`.

## مصادر البيانات والتراخيص

- التعداد والفروع: ملفان مقدّمان من المستخدم، محفوظان محلياً بعد تبسيطهما.
- حدود المملكة: Natural Earth (ملكية عامة)، مبسّطة إلى 76 نقطة.
- لا تُضمّن أي بلاطات OpenStreetMap العامة في المستودع، ولا يُفعّل تنزيلها الجماعي. يمكن للمستخدم إدخال قالب بلاطات مرخّص من الإعدادات.
- أي مفتاح Gemini يُدخله المستخدم يُحفظ في keystore الجهاز ولا يُرفع إلى المستودع أو APK.
